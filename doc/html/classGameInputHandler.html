Detailed Description

Gère les entrées simples du joueur.

Cette classe lit l'état de InputManager et transforme les touches clavier ou les clics souris en actions simples : déplacement du curseur, pause, sélection d'une tour, placement ou lancement de vague.

Elle ne possède pas le monde du jeu. Les actions importantes sont données sous forme de callbacks.
