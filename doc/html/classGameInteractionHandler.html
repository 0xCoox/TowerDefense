Detailed Description

Gère les interactions avancées entre le joueur, le HUD et le monde.

Cette classe conserve l'état du curseur, la tour sélectionnée, le drag-and-drop depuis la palette du HUD et la sélection verrouillée d'une tour existante.

Elle sert d'intermédiaire entre InputManager, Hud, GameWorld et TextureManager.
