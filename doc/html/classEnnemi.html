Detailed Description

Représente un ennemi se déplaçant sur le chemin de la carte.

Un ennemi possède des points de vie, une vitesse, une résistance, un type et une progression sur le chemin. Certains ennemis peuvent être volants.

Met à jour le déplacement de l'ennemi sur le chemin.

L'ennemi avance vers le point suivant du chemin. Cette fonction gère aussi le ralentissement temporaire appliqué par les tours de glace.
