Detailed Description

Encapsule le rendu SDL2 du jeu.

Cette classe centralise les appels à SDL_Renderer afin que les autres classes du projet n'aient pas à manipuler directement SDL_Rect, SDL_RenderCopy, SDL_RenderCopyEx ou SDL_RenderDrawLine.

Elle est responsable de :

  • effacer et présenter l'écran ;
  • dessiner des rectangles, lignes et points ;
  • afficher des textures ;
  • afficher du texte avec SDL_ttf.
