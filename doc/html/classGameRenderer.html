Detailed Description

Responsable de l'affichage complet du jeu.

GameRenderer dessine la carte, les tours, les ennemis, les projectiles, la portée des tours, le HUD, les boutons et les aperçus de placement.

Cette classe ne doit pas modifier la logique du jeu : elle doit seulement afficher l'état courant.
